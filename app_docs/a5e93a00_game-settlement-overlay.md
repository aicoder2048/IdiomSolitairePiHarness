# 对局结束结算画面

最后一轮 Bot 成功提交或放弃并结算时，现在会展示完整对局总结：标题、总比分与胜负、每轮人类与 Bot 的出词及该步得分，以及继续游戏提示。跳过、超时、提示和 Bot 放弃也会按已记录结果显示；放弃的 Bot 回合明确列出 0 分。计分和结束条件未变。

## 展示方式

`src/extension/view.ts` 的纯函数 `finalLines(game)` 生成两种界面共用的文字行，按历史顺序列出每轮。`src/extension/index.ts` 只在结算结果 `gameOver` 为真时触发展示：TUI 使用居中 overlay，按任意键关闭；普通回合卡片仍保留，但不会再额外追加终局卡片。非 TUI 模式（RPC、JSON、print）将相同总结追加为终局卡片。Overlay 是非阻塞的，不等待玩家关闭才完成 Bot 工具；若自定义 UI 出错，则回退为一次终局卡片。

`src/extension/panel.ts` 提供可关闭面板，复用既有面板的宽度处理与样式。总结只面向玩家，不加入模型上下文，也不额外调用模型。每次实际终局结算触发一次；之后重开、撤销或增加轮数继续对局，新的终局仍可再次展示。

## 使用与验证

正常游戏至最后一轮即可看到总结。按任意键关闭 TUI 浮层；输入 `/restart` 重开，或 `/rounds <N>` 增加总轮数继续。

离线测试覆盖了总结文字（含跳过、提示、超时及 Bot 放弃）、面板关闭、TUI 与非 TUI 路由、终局只展示一次及 UI 失败回退。运行 `just test` 验证完整测试集。玩家操作说明见 `README.md`；展示上下文规则见 `AGENTS.md`。

## 2. 重要的行为 / API 变化

### 包名 / import
- 所有 npm scope `@mariozechner/*` → `@earendil-works/*`：`pi-coding-agent`、`pi-ai`、`pi-agent-core`、`pi-tui`（`04-build-on-pi/01-extensions.md`、`03-customize-pi/05-packages.md`）。旧 import 需全部替换。
- Pi 包里这些 host 包 + `typebox` 必须放 `peerDependencies: "*"`，**不要**放进 `dependencies`；Pi 检测到会给 extension warning（`05-packages.md`）。旧文档推荐的 `bundledDependencies` 写法已不再出现，改为"published tarball 内 + node_modules 路径引用"。
- npm 安装需 Node.js ≥ 22.19，推荐 `npm install -g --ignore-scripts`；另有 `curl https://pi.dev/install.sh | sh` 与 Nix flake（`02-quickstart.md`）。

### Project trust（新机制，最容易踩）
- 项目 `.pi/settings.json`、`.pi/mcp.json`、`.pi/extensions|skills|prompts|themes`、`.pi/SYSTEM.md|APPEND_SYSTEM.md`、项目 `.agents/skills` **需授信后才加载**（`02-run-pi/04-security.md`）。
- print / JSON / RPC 模式无法弹窗：默认 `defaultProjectTrust: "ask"` 时这些资源会被**跳过**。自动化运行需加 `-a/--approve`（或 `-na/--no-approve`），或在 agent-dir settings 设 `"always"`，或用 `/trust` 预存（`~/.pi/agent/trust.json`）。
- 例外：`sessionDir` 在授信前读取；`AGENTS.md`/`CLAUDE.md` 等 context files 不受 trust 控制。新增 `AGENTS.override.md`（`01-configuration.md`）。
- 新 extension 事件 `project_trust`：只有用户级与 CLI `-e` 的 extension 能参与（`01-extensions.md`）。

### ExtensionAPI（`04-build-on-pi/01-extensions.md`）
- 新方法：`pi.registerMcpServer()/unregisterMcpServer()/getMcpServers()`、`pi.registerVirtualModel()/unregisterVirtualModel()`、`pi.registerToolRenderer()`、`pi.registerEntryRenderer()`（旧文档为 `registerMessageRenderer`）。`pi.on()` 现在返回 unsubscribe 函数。
- 新事件：`agent_before_settle`（可追加 entry 并请求一次 continuation）、`agent_settled`（最终、只通知）、`provider_stream_event`、`context_with_system`、`cache_warming_decision`、`mcp_servers_change`、`session_compact_failed`（`09-compaction.md`）。`turn_end` 也可 `continue: true`。
- `before_agent_start` 暴露 `systemPromptOptions`；返回 `systemPrompt` 或 `forceSystemPrompt` 会整体替换 prompt。
- Tool 定义新增：`exposure`（`direct|model-only|codemode|deferred|hidden`）、`namespace`、MCP 风格 `annotations`、`outputSchema` + `structuredContent`、`prepareLoadout()`、`terminate: true`；`ctx.executeTool()` / `ctx.tools` 可嵌套调用工具。工具不能 unregister，只能重注册为 `hidden`。
- 文件改写工具应包在 `withFileMutationQueue()` 里；`user_bash` handler 出错会阻止命令（不再回落本地执行）。
- 新 `ctx.mode`（判断 `"tui"`）、`ctx.modelRegistry.streamSimple()/classify()/generateImages()`。factory 中不要起进程/定时器，放到 `session_start`。

### SDK（`04-build-on-pi/06-sdk.md`）
- 旧示例的 `AuthStorage.create()` + `ModelRegistry.create()` 传参不再出现；新选项为 `modelRuntime`（`ModelRuntime`）、`model`、`thinkingLevel`、`scopedModels`、`settingsManager`、`sessionManager`、`resourceLoader`、`tools/noTools/excludeTools/customTools`。旧 `createAgentSessionRuntime` 不再出现，改述 `AgentSessionRuntime`。
- streaming 中调用 `prompt()` 必须指明 steer 或 follow-up，否则 reject；`steer()/followUp()` 返回 `"queued"|"handled"`。
- 用 `agent_settled`（而非 `agent_end`）判断 Pi 不会再自动继续。
- CLI 自带的 `codemode`/`tool_search`/MCP 是 built-in extension，**SDK 默认不加载**：需 `createCodemodeExtension()`、`createToolSearchExtension()`、`createMcpExtension()` 加入 `extensionFactories` 并调用 `session.bindExtensions()`。

### Settings（`05-reference/04-settings.md`）
- 默认值变化：`theme` `"dark"`→`"system"`；`transport` `"sse"`→`"auto"`（新增 `"websocket-cached"`）；`defaultThinkingLevel` 默认 `"medium"`，新增级别 `"max"`；`retry.provider.maxRetries` 默认 `0`、`retry.provider.timeoutMs` 默认 = `httpIdleTimeoutMs`。
- 新键：`defaultTools`（支持 `+name/-name`）、`defaultProjectTrust`、`modelThinkingLevels`、`cacheWarming`、`showCacheMissNotices`、`codemode.mode/inlineBudget`、`compaction.modelOverrides`、`tuiMode`（默认 `"fullscreen"`）、`fullscreen*` 四项、`outputPad`、`externalEditor`、`httpProxy`、`httpIdleTimeoutMs`、`websocketConnectTimeoutMs`、`retry.maxAgentDelayMs`、`terminal.hyperlinks/images/trueColor/showTerminalProgress`、`markdown.mermaid`、`enableAnalytics`。`quietStartup` 可取 `"header"`。
- 内置 extension 名：`builtin:mcp`、`builtin:llama.cpp`、`builtin:codemode`、`builtin:tool-search`，默认加载，`extensions: ["-builtin:mcp"]` 关闭。
- 内置工具新增 `powershell`；默认工具仍为 `read,bash,edit,write`。

### CLI（`05-reference/01-cli.md`）
- 新子命令：`pi auth check|print-api-key|print-bearer-token`、`pi mcp add|remove|list|login|logout`。
- `pi update` **语义变化**：旧版 = 更新 pi + 包；新版无参数只更新 Pi 本身，包用 `--extensions`，全部用 `--all`，模型目录用 `--models`。
- 新 flag：`--session-id`、`-xt/--exclude-tools`、`--tui-mode`、`-a/--approve`、`-na/--no-approve`、`--offline`、`--use-theme`；`--thinking` 支持 `max`；`--system-prompt/--append-system-prompt` 接受文件路径。
- 重定向 stdin/stdout 时自动进入 print 模式；`--mode text` 不再等于一次性运行。
- 新 slash 命令：`/thinking`、`/llama`、`/import`、`/bug`、`/trust`；`/export` 支持 JSONL；`/share` 不再写"GitHub gist"，改为上传返回 viewer link（`PI_SHARE_VIEWER_URL`）。

### 环境变量（`05-reference/05-environment-variables.md`）
- 新：`PI_CODING_AGENT_SESSION_DIR`、`PI_OFFLINE`、`PI_SHARE_VIEWER_URL`、`PI_RADIUS_GATEWAY`、`PI_HYPERLINKS`、`PI_IMAGE_PROTOCOL`、`PI_TRUE_COLOR`、`PI_TUI_ESC_TIMEOUT`。
- 进程标记 `AI_AGENT=pi`、`PI_CODING_AGENT=true`；LLM 调用的 `bash`/`powershell` 收到 `PI_SESSION_ID/PI_SESSION_FILE/PI_PROVIDER/PI_MODEL/PI_REASONING_LEVEL`（SDK 嵌入时不设进程标记）。

### Session 格式（`05-reference/08-session-format.md`）
- 版本号仍为 **v3**，文件路径改为 `<timestamp>_<session-id>.jsonl`（id 可自定义）。
- 新增：`role: "system"` 消息（记录 prompt sections 与 `toolsAdded/toolsRemoved` 增量）、`usage` entry（如 `cache_warm`）、`context_edit` entry、compaction 的 `systemMessage` 字段、assistant 消息的 `thinkingLevel`；virtual model 状态存为 `customType: "pi.virtual-model-state"`。解析器需容忍新 entry 类型与未知 `kind`。

### RPC / JSON（`05-reference/10-json.md`、`11-rpc.md`、`12-rpc-commands.md`）
- 新命令：`clear_queue`、`get_available_thinking_levels`、`get_entries`、`get_tree`。
- 新事件：`agent_settled`、`entry_appended`、`session_info_changed`、`thinking_level_changed`、`bash_execution_update`（带原命令 id）、`summarization_retry_*`。
- 强调严格 LF 分帧：不要用 Node `readline`（会在 U+2028/2029 切分）；TS 客户端推荐导出的 `RpcClient`。

### 其它
- MCP：旧 usage 明说"不内置 MCP"；新版内置，`mcp.json`（user `~/.pi/agent/mcp.json`，project `.pi/mcp.json`），工具名 `mcp__<server>__<tool>`，默认 exposure 为 `codemode`（`03-customize-pi/06-mcp.md`）。
- Keybindings 只有新增：`app.message.copy`、`app.thinking.save`、`tui.altScreen.*`（fullscreen 滚动/搜索）、`tui.editor.historyNext/Previous`（`05-reference/06-keybindings.md`）。
- Custom provider：可注册完整 `Provider`（`@earendil-works/pi-ai`）或旧 `ProviderConfig`；模型新增 `type: "image" | "classifier"`（`04-build-on-pi/02-custom-provider.md`）。
